# 데이터 (실데이터 지식그래프 v0.3.4)

## 출처 표시 (필수)

원자료: 한국과학기술정보연구원, 국가과학기술지식정보서비스(NTIS) OpenAPI 과제검색·성과검색(공공누리 제1유형), 2026년 10월 수집. 본 데이터는 원자료를 RDF로 변환·집계한 가공본이다.

공공누리 제1유형은 출처를 표시하면 상업적 이용과 변경(2차적 저작물 작성)을 포함한 이용을 허용한다. 가공본은 같은 출처 표시 조건을 유지하여 CC BY 4.0으로 배포한다.

## 공개하지 않은 것과 사유

| 항목 | 사유 |
|---|---|
| NTIS 원본 API 응답(`data/raw/`, 약 343MB)과 과제 단위 중간 산출물(약 40MB) | 이용 조건상 공개는 가능하나 용량이 크고, 수집 스크립트와 인증키로 같은 응답을 다시 받을 수 있어 저장소에 두지 않았다. 수집 조건과 시각은 `nrdp-domain.ttl`의 수집 활동(`ex:ACT_COLLECT`)에 기록되어 있다. |
| NTIS OpenAPI 인증키 | 개인에게 발급된 키이다. |
| 연구책임자·참여연구원 성명, 사업자등록번호 | 수집 단계에서 옮기지 않았다. 사업 포트폴리오 평가에 필요하지 않은 개인·기관 식별 정보이다. |
