분류체계의 판(edition)과 판 사이 대응표를 표현하는 모듈. 국가과학기술표준분류 2018·2023 개정판처럼 기간 중 바뀌는 분류를 판별 개념으로 보존하고 대응 관계를 기록한다.

Module for classification editions and inter-edition correspondences (XKOS-based), used to keep technology-field codes of different classification editions apart.

배분 비중 kosv:AllocationShare

IRI
https://w3id.org/nrdp/kosv#AllocationShare
영문 레이블
Allocation share
설명
분할·통합 후 재분할 연관에서 (원천, 대상) 쌍별 배분 비중. 집계값이 이 비중에 의존하므로 근거를 함께 기록한다. 같은 원천의 비중 합 = 1 은 SHACL로 검사.
상위 클래스·제약

=1 kosv:fromConcept.skos:Concept
=1 kosv:toConcept.skos:Concept

분류체계 kosv:Classification

IRI
https://w3id.org/nrdp/kosv#Classification
영문 레이블
Classification
설명
판을 묶는 분류체계 자체(예: 국가과학기술표준분류). XKOS는 이를 skos:Concept 로 모델링하도록 권고하나, 여기서는 판(ConceptScheme)과 구분되는 별도 클래스로 둔다.

Harmonization run
설명
