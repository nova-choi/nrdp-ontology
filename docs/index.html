이용

모든 IRI는 w3id.org에서 내용 협상(content negotiation)으로 응답한다. 브라우저는 이 문서로, Accept: text/turtle·application/rdf+xml·application/ld+json·application/n-triples 요청은 해당 직렬화로 연결된다.
